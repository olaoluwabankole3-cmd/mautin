# Mautin Atelier

A luxury-editorial, responsive fashion website built as a lightweight static site using HTML, CSS, and vanilla JavaScript.

## Preview locally
Open `index.html` in a browser. No build step or environment variables are required.

## Deploy on Vercel
1. In Vercel, choose **Add New → Project**.
2. Import `olaoluwabankole3-cmd/mautin`.
3. Keep the project framework as **Other** and the root directory at the repository root.
4. Deploy. Vercel can serve `index.html` directly as a static site.

## Before the client presentation
- Replace the temporary editorial image URLs in `index.html` with Mautin Atelier's approved campaign/product photographs. These photos are visual stand-ins, not verified photographs of the client's own garments.
- The site uses the name **Mautin Atelier** and links all enquiry actions to the Instagram profile/DM. No unverified address, phone number, pricing, testimonials, or biography have been added.
- Confirm the wording, service categories, and commission process with the designer before treating them as final brand copy.

## Main file
- `index.html` — full responsive site, styles, motion, navigation and enquiry links.
